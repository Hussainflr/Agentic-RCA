# AI4I Fault Code Reference

## TWF - Tool Wear Failure

Tool wear failure indicates the cutting tool may have exceeded useful life. Recommended checks include visual tool inspection, tool-life counter review, replacement history, and surface-quality review.

## HDF - Heat Dissipation Failure

Heat dissipation failure is associated with poor thermal removal. Recommended checks include coolant path inspection, blocked vent checks, heat exchanger condition, and ambient/process temperature review.

## PWF - Power Failure

Power failure is associated with abnormal power requirements caused by torque and rotational-speed conditions. Recommended checks include motor current trend, drive alarms, torque sensor verification, and drivetrain loading.

## OSF - Overstrain Failure

Overstrain failure is associated with mechanical stress from load, torque, and tool wear. Recommended checks include bearing inspection, coupling alignment, fixture condition, and operating envelope review.

## RNF - Random Failure

Random failure has no deterministic signature in the AI4I dataset. Recommended checks include maintenance logs, intermittent electrical faults, operator notes, and inspection findings.
